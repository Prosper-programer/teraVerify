# TerraVerify

TerraVerify is a comprehensive platform for land title verification, property acquisition, and surveyor services. 

## Architecture

* **Client layer:** React Native mobile application and web dashboards.
* **Application layer:** Node.js and Express REST API.
* **Data layer:** MySQL database.

## Technology Stack

* React Native
* Expo
* Node.js
* Express.js
* MySQL
* JWT
* REST API
* React/Vite
* TypeScript

## Features & Workflows

### Verification Claim
The platform supports a manual cadastral verification workflow performed by a land surveyor.

### Payment
The prototype simulates MTN Mobile Money and Orange Money payments. (Real provider API integration is planned for production.)
